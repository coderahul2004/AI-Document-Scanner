# AI Document Scanner

Chat with your PDF, DOCX, Excel, CSV and TXT files using RAG and MCP.

## Features
- Upload and index many file types
- Ask questions and get answers with the source file name
- MCP server with search and list tools
- Chat history and delete files option

## Tech Used
Python, Streamlit, Gemini, ChromaDB, LangChain, MCP

## How to Run
1. Install packages: pip install -r requirements.txt
2. Make a .env file and add: GOOGLE_API_KEY=your_key_here
3. Run: streamlit run app.py
